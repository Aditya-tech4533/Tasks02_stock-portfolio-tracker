📈 Stock Portfolio Tracker
📌 About the Project

The Stock Portfolio Tracker is a simple Python project that calculates the total investment value of stocks based on predefined stock prices and user-entered quantities.

This project was developed as Task 2 to practice Python programming fundamentals.

✨ Features
Displays available stocks and their prices.
Accepts stock symbols and quantities from the user.
Calculates individual stock investment values.
Calculates the total portfolio investment.
Validates stock symbols and quantities.
Saves portfolio details to a text file (portfolio.txt).
🛠️ Technologies Used
Language: Python 3
Concepts: Dictionaries, loops, conditional statements, user input, arithmetic operations, exception handling, and file handling.
📂 Project Structure
Tasks02_stock-portfolio-tracker/
├── stock_tracker.py
├── README.md
└── portfolio.txt (generated when saving)

🚀 How to Run
Install Python 3 on your computer.
Clone or download this repository.
Open a terminal in the project directory.
Run the following command:
python stock_tracker.py

Enter a stock symbol, such as AAPL or TSLA.
Enter the quantity of shares.
Type done to calculate the total investment.
Choose yes when prompted to save the portfolio to a text file.

🧮 Calculation

The investment value is calculated using:

Investment Value = Stock Price × Quantity

Total Investment = Sum of all individual stock investments
